# Glossário - Capítulo 1: Understanding Large Language Models

* **LLM (Large Language Model):** Um modelo de rede neural em grande escala projetado para compreender, gerar e interagir usando linguagem humana.
* **Transformer:** A arquitetura de rede neural introduzida em 2017 que serve como base para a maioria dos LLMs modernos, caracterizada pelo uso de mecanismos de autoatenção (*self-attention*).
* **Tokenização:** O processo de dividir um texto de entrada em unidades menores chamadas tokens (que podem ser palavras, subpalavras ou caracteres) para que o modelo possa processá-los.
* **Embedding:** A conversão de tokens em vetores numéricos contínuos, permitindo que o modelo capture o significado semântico das palavras.
* **Pré-treinamento (Pre-training):** A fase inicial de treinamento onde o modelo consome terabytes de texto para aprender a estrutura da linguagem, gramática e fatos do mundo, prevendo a próxima palavra.
* **Fine-Tuning (Ajuste Fino):** A etapa secundária de treinamento onde um modelo pré-treinado é ajustado usando um conjunto de dados menor e específico para realizar tarefas particulares (como responder a perguntas ou agir como assistente).
